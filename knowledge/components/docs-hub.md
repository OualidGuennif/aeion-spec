# Documentation hub

## Intent

Say what the generated cockpit is now. It was built by the template's AxiomSpec engine
(`tools/axiom/`), which Æion Template 4.0.3 removed; the pages are kept as the last generated view and
nothing regenerates or checks them. AxiomSpec now lives in aeion-framework.

## Data sources

`knowledge/spec/spec.json` and its receipts in `knowledge/spec/evidence/`, as of the 4.0.3 update.

## Inputs

None: no tool reads or writes the cockpit any more.

## Outputs

`docs/README.md` and `docs/generated/`, unchanged since their last generation.

## Invariants

- Nothing under `docs/generated/` is hand-edited; a stale page is a known limit, not a defect to patch.
- The OKF component docs in `knowledge/components/` are the spec; the cockpit is never cited as a source of truth.

## Determinism

Not applicable: nothing is generated.

## Acceptance checks

- [ ] Migrating `knowledge/spec/spec.json` with aeion-framework's `qa/migrate_0_1.py` then `qa/migrate_0_2.py`,
  serving it and setting `tools/aeion-settings framework <url>` (owner) retires this doc and the cockpit.

## Out of scope

The Spec Studio's release archive and card views (see [spec-studio](spec-studio.md)).
